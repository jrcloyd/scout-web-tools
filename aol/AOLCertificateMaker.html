1. Scout Data Import & Arrow Maker
Input Format & Camp Handling:
  • Download your rank report from Scoutbook as CSV/TSV with columns for ranks and up to two camp attendance entries.
  • Values Required: A cell marked with "Awarded", "Yes", "Y", "X", or starting with "Approved" will be recognized as completed.
  • Column Naming: Headers are matched case-insensitively. Arrow of Light matches either Arrow of Light or AOL.
  • Camp Placement: If two camps are provided, the earlier year is placed between Bear and Webelos; the later year is placed between Webelos and AOL.
  • Try an Example: Don't have your own file handy? 📋 Click here to use example data.
Note: Scout data used in this tool is used only locally by this page and does not transmit to a server.
